# 🗜️ Archive Extractor

Умный CLI-распаковщик архивов с поддержкой модов на Lua.

## ✨ Возможности

- **Поддержка форматов:** ZIP, RAR, 7Z, TAR, GZ, BZ2, XZ
- **Умная логика:** Если в корне архива есть `.lua` файлы → распаковка в отдельную папку
- **Режимы работы:**
  - `overwrite` — замена существующих файлов (рекомендуется для модов)
  - `skip` — перенос только новых файлов
- **Многопоточность:** Параллельная обработка архивов
- **Безопасность:** Защита от Path Traversal атак
- **Красивый интерфейс:** Интерактивное CLI-меню с прогресс-барами
